# Bundled visual assets

## `models/worker_taking_a_walk.glb`
- Animated Mixamo walk cycle (`mixamo.com` clip)
- Used for walking / evacuating personnel on plant overview and CCTV wall

## `models/boneworks_-_omni_worker.glb`
- Textured static Omni worker (no clips)
- Used for on-task / working personnel poses

## `models/factory_industrial_installation.glb`
- Large textured industrial plant installation
- Primary process-block geometry on plant overview + chemical/mechanical/flammable CCTV interiors

## `models/solar_energy_for_industry.glb`
- Industrial solar / electrical yard
- South-yard geometry on plant overview + electrical/general CCTV interiors

Place files under `public/models/` so Next.js can serve them at `/models/...`.
